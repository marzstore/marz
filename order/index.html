Informasi Kode Verifikasi

Saat admin melakukan login ke akun kamu, Roblox akan mengirimkan kode verifikasi sekali pakai ke Gmail kamu.

  • 1. Lakukan pemesanan dan isi form dengan benar.
  • 2. Admin akan mulai memproses pesanan dan mencoba login ke akun.
  • 3. Admin akan meminta kode verifikasi yang masuk ke Gmail kamu di obrolan chat WhatsApp.
  • 4. Kirimkan kode verifikasi tersebut melalui chat WhatsApp admin agar proses login dapat dilanjutkan.
Kode verifikasi bersifat sementara dan hanya bisa digunakan sekali. Tetap pantau WhatsApp untuk kelancaran proses joki.
